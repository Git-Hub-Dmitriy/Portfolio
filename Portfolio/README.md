# 📝 Personal Portfolio Website

Мой личный сайт-портфолио для демонстрации проектов, навыков и опыта. Проект разработан с упором на производительность, чистоту кода и современные архитектурные подходы.

## 🚀 Стек технологий

- **Framework**: Next.js 16 (App Router)
- **Frontend**: React, HTML5, TypeScript
- **Styling**: Modern CSS Modules
- **State Management**: Zustand
- **Localization**: Кастомное решение на Proxy + Динамический импорт словарей
- **Testing**: Vitest, React Testing Library, Playwright

---

## 💡 Особенности и технические решения

### 🌐 Легковесная мультиязычность (EN / UA)

Вместо использования тяжелых сторонних библиотек реализована кастомная система локализации:

- Текущая локаль сохраняется в **Cookie**.
- Запросы обрабатываются через `proxy.ts`, который перехватывает и передает нужную локаль.
- Переводы загружаются на лету с помощью **динамического импорта json-словарей**, что минимизирует размер бандла.

### 🧬 Архитектура и Состояние

- **Zustand**: Используется один лаконичный слайс для управления интерактивными элементами интерфейса.
- **Динамический роутинг**: Реализованы динамические маршруты для детальных страниц проектов с описанием, скриншотами, ссылками на GitHub и Production-деплой.

### 🎨 Анимации и UX

- **IntersectionObserver**: Анимации появления элементов при скролле реализованы через нативный API, что обеспечивает максимальную плавность и высокую производительность

### 🧪 Тестирование (Testing)

- Проект придерживается принципа целесообразного тестирования. Полностью покрыта тестами (**Vitest + React Testing Library**) ключевая бизнес-логика — стейт-менеджер Zustand (хранилище и его экшены), так как он отвечает за весь интерактив на сайте.
- Инфраструктура подготовлена к сквозному тестированию с помощью **Playwright**.

## 🛠️ Запуск проекта

1. **Установка зависимостей:**

   ```bash
   npm install
   ```

2. **Запуск в режиме разработки:**

   ```bash
   npm run dev
   ```

3. **Запуск тестов:**
   ```bash
   npm run test:ui
   ```
