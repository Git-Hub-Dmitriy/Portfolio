# 🛒 My First E-Commerce SPA

Этот проект — полноценный концепт одностраничного интернет-магазина (SPA), в котором вся ключевая логика (роутинг, корзина, фильтрация, пагинация, авторизация и даже карусель) реализована **вручную**, без использования готовых библиотек-конструкторов.

---

## 🛠️ Технологический стек (Tech Stack)

- **Core:** JavaScript (ES6+), React 18, HTML5
- **Routing:** React Router v6 (включая вложенные роуты и `searchParams`)
- **State Management:** Redux Toolkit (RTK)
- **Styling:** SCSS (SASS)
- **Build Tools:** Webpack 5 (базовая кастомная настройка с нуля)

---

## 🚀 Основной функционал (Features)

- **Клиентский роутинг (React Router 6):** Реализовано порядка 5 основных страниц, динамический роут для карточки товара, а также система вложенных (nested) маршрутов.
- **Имитация Личного Кабинета и Защита Роутов (HOC):** Полноценная имитация авторизации. Доступ к профилю защищен с помощью High-Order Component (HOC) — неавторизованных пользователей редиректит на страницу логина. Данные профиля "админа" хранятся статически в файле `data/users.js`. Данные для входа: Логин/Пароль: admin/admin

- **Корзина и Wishlist (Избранное):**
  - Работают на базе синхронизации с `localStorage`.
  - В корзине и вишлисте можно удалять товары и динамически менять их количество с мгновенным пересчетом.
  - _Нюанс:_ Список желаемого (Wishlist) доступен только залогиненным пользователям (также срабатывает редирект).
- **Кастомная фильтрация и сортировка:** На страницах Каталога (`Shop`) и Блога реализована ручная фильтрация, завязанная на `searchParams` URL (чтобы ссылкой на отфильтрованный список можно было поделиться), а также сортировка товаров.
- **Ручная пагинация:** Постраничный вывод элементов без использования сторонних плагинов.

---

## 📁 Структура личного кабинета (Вложенные роуты)

Внутри профиля реализована модульная структура:

- `Wishlist` (Список желаемого с возможностью управления товарами).
- `Orders` (История старых заказов).
- `Settings` (Настройки профиля).

## 📦 Быстрый старт (Installation & Usage)

### Требования

Для запуска проекта вам понадобится установленный [Node.js](https://nodejs.org) (рекомендуется LTS версия).

### Установка и запуск

1. Клонируйте репозиторий:

   ```bash
   git clone https://github.com/Git-Hub-Dmitriy/Portfolio.git
   cd Ecobazar
   ```

   _Или используйте команду, которая прописана в вашем `package.json` (например, `npm run dev`)_.

2. Откройте проект в браузере:
   http://localhost:8000
